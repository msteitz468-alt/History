# Processing List — World History Wiki

Prioritized ingestion sequence for Claude Code. All files listed here are present
in the collection. Work through phases in order — each phase builds the structural
skeleton that makes the next phase's material more valuable.

Do not begin a new phase until the previous phase's pages are written, cross-linked,
and index.md is updated. Append a log entry after completing each file.

---

## Instructions for Claude Code

1. All source files are PDFs located in the directory you have been pointed to.
   Treat each file path as relative to the root of the source collection.
2. For each file: read it, extract key historical content, write or update all
   affected wiki pages per CLAUDE.md, update index.md, and append to log.md.
3. Do not ingest files out of phase order. Phase 1 is the structural skeleton —
   everything else depends on it being solid.
4. When you encounter duplicate files (marked with `(1)` or `(2)` suffixes),
   ingest only the first copy. Ignore duplicates.
5. After completing each phase, pause and report: pages created, pages updated,
   controversies flagged, and gaps identified.

> **Annotation key (added 2026-06-12):** entries tagged ***Missing*** are not present in the
> collection (no file found); ***Missing (corrupt conversion)*** means a file exists but holds only
> front matter / page-marker artifacts and cannot be read; parenthetical notes record where a work was
> ingested via a different edition. All named entries *without* a tag are present and have been ingested.
