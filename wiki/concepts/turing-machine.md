# Turing Machine (Universal Turing Machine)

The Turing machine is a formal mathematical model of computation invented by Alan Turing in 1936. It consists of an infinite tape divided into cells, a read/write head that moves left or right, and a finite set of states with transition rules. The model defines what it means for a function to be “computable” by a mechanical process.

Turing proved that there exists a single “universal” Turing machine that can simulate any other Turing machine given its description on the tape. This established the theoretical possibility of a general-purpose programmable computer.

## Emic vs. Etic

In 1936 it was a purely mathematical construct solving a problem in logic (the Entscheidungsproblem / decision problem). After 1945 it became the conceptual foundation for the architecture of real digital computers (stored program, software as data).

## Application and Limitations

The model is extremely general: any algorithm that can be executed by any computer can, in principle, be executed by a Turing machine (Church–Turing thesis). It does not address physical speed, memory limits, or energy; those are engineering questions.
