# Battle Template — moved

> **The canonical battle-analysis template now lives at [[hubs/warfare/templates/battle-analysis-template|templates/battle-analysis-template]].**

This file previously held a shorter, duplicate template. To prevent the two drifting apart, there is now a **single source of truth**: the expanded template at `hubs/warfare/templates/battle-analysis-template.md`, which defines both the standardized frontmatter spec and the full West Point–style section set (target 2,500–3,500+ words, OOB and casualty tables, all nine principles of war, modern-doctrine parallels, and sourced historiography).

Copy that template to `hubs/warfare/[period]/[war]/[battle].md` and fill it in. See **[[hubs/warfare/classical-antiquity/second-punic-war/battle-of-cannae|Battle of Cannae]]** for the reference exemplar that sets the standard.
